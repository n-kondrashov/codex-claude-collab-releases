# Codex + Claude Relay

Публичные VSIX-релизы расширения для VS Code. Исходники и сборка хранятся в отдельном приватном репозитории.

Расширение добавляет общий текстовый чат для Codex CLI и Claude Code. Можно отправить задачу одному агенту, передать её обоим по очереди или попросить второго проверить результат первого. Голосового ввода и озвучки в расширении нет.

## Установка

1. Установите VS Code 1.90 или новее, авторизуйте Codex CLI и Claude Code CLI в своих учётных записях.
2. Скачайте VSIX из [последнего релиза](https://github.com/n-kondrashov/codex-claude-collab-releases/releases/latest).
3. Сверьте SHA-256 файла с приложенным файлом `.sha256`.
4. В VS Code выберите **Extensions → … → Install from VSIX…**, откройте проект и нажмите значок **Codex + Claude** на боковой панели.

Для Claude Code требуется версия 2.1.259 или новее. Если VS Code не находит CLI, укажите абсолютные пути в настройках `codexClaude.codexPath` и `codexClaude.claudePath`.

## Важно знать

- Агенты запускаются последовательно и видят общий контекст проекта в `.collab/`. Не записывайте туда секреты, которые нельзя передавать обоим агентам.
- Codex может запросить разрешение прямо в VS Code. Запросы дополнительных разрешений Claude пока не показываются в интерфейсе и отклоняются; в чате появится предупреждение о возможном неполном ответе. Разрешения можно настроить в Claude Code и повторить запрос.
- VSIX запускает локальные CLI с доступом, который вы предоставили им в своей среде. Устанавливайте расширение только из этого репозитория и доверяйте лишь проверенным рабочим папкам.
